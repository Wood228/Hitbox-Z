# Hitbox-Z

Client-side PvP hitbox customization mod for Minecraft 1.21.4 on Fabric.

## Planned features

- Visual entity hitbox rendering
- Adjustable hitbox width and height
- Custom hitbox color and line thickness
- Toggle hotkey
- Client-side configuration GUI
- Persistent settings

The first implementation will focus on **visual hitboxes**. This keeps the initial feature set separate from changing Minecraft's actual entity collision/attack bounding boxes.

## Development

- Minecraft: 1.21.4
- Fabric Loader: 0.16.10
- Java: 21+
- Mod ID: `hitboxz`
